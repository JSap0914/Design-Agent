## 🎯 핵심 포인트

### **1. 역할 분담 명확**

```
LangGraph (자동):
├─ 단순 반복 작업
├─ 데이터 변환
├─ 검증 및 품질 체크
└─ 문서 생성

사용자 (수동):
├─ 창의적 디자인 결정
├─ Google AI Studio 조작
├─ 디자인 만족도 판단
└─ 최종 코드 선택
```

### **2. 일시정지 메커니즘**

```
LangGraph State:
├─ pause_state: "waiting_for_code"
├─ PostgreSQL Checkpointer로 상태 저장
├─ 사용자가 작업 완료할 때까지 대기
└─ 코드 업로드 시 자동 재개
```

### **3. 유연성**

```
사용자 선택의 자유:
├─ Google AI Studio에서 원하는 만큼 시간 투자
├─ 여러 버전 생성 및 비교
├─ 만족할 때까지 반복
└─ 직접 코드 수정 가능
```
